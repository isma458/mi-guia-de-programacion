## 1. ¿Qué es programar?
**Programar** = darle instrucciones a una computadora para que haga algo.  
Desde calcular, mostrar cosas en pantalla, hasta mover un robot o crear una app.

Todo empieza con **lógica**:
- “Si pasa A, entonces haz B.”  
- “Repite esto 5 veces.”
